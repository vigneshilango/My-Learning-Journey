# 6-Pack Challenge (browser)

Open `index.html` in a browser. All data stays on your device via `localStorage`.

## Files

| File | Purpose |
|------|---------|
| `index.html` | App UI, styles, and logic |
| `recipes.json` | Meal database (kitchen / grocery) |
| `workout-plans.json` | 6-phase workout templates |
| `exercise-tips.json` | Exercise coaching text for the ⓘ modal |
| `phases.json` | Challenge phase metadata (weeks, target weights) |

**Note:** JSON files must sit in the same folder as `index.html`.

## Live site

After GitHub Pages deploys, open:

**https://vigneshilango.github.io/My-Learning-Journey/**

Enable Pages once if needed: repo **Settings → Pages → Build and deployment → Source: GitHub Actions**.

All progress still saves in your browser via `localStorage` (per device, not synced to GitHub).
